# BLP-003 — Rúbrica de evaluación

> **REQUISITO DE GOBERNANZA (§7.3, Art. XII):** esta rúbrica la escribe un **humano**
> (el Arquitecto). El agente NO puede redactarla ni evaluar con una rúbrica propia.
> Este archivo define el PROCEDIMIENTO y queda a la espera de la autoría humana.

## Procedimiento de evaluación ciega

1. El evaluador recibe las respuestas de cada formato **sin saber cuál es cuál** (etiquetas ciegas A–F, el mapeo formato↔etiqueta queda sellado aparte).
2. Evalúa cada respuesta contra la rúbrica con una escala explícita (p. ej. 0–3).
3. Se registran dos evaluadores cuando sea posible; se reporta el **acuerdo entre evaluadores** (techo) y el acuerdo del evaluador con el patrón.
